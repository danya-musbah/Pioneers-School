## ما لم يتم التحقق منه

- لم يُفتح `.env` ولم تُعرض قيمه؛ لم يتم فحص أسرار منصة Supabase.
- لم يتم الاتصال بمشروع Supabase أو تشغيل migrations أو Edge Functions أو تنفيذ كتابة/نشر.
- لم يختبر تسجيل دخول حقيقي أو قراءة بيانات حقيقية أو خروج حي أو رابط Storage موقع أو API إداري أو استعادة نسخة.
- لم يجر اختبار شامل للمتصفحات/الأجهزة/الإتاحة أو مراجعة اختراق؛ وصف CSS/ARIA مستند إلى الكود فقط.
- لم يُفحص catalog لقاعدة منشورة؛ migrations هي الدليل المحلي فقط.
- فشل اختبار محلي واحد كما في GAP-012؛ لم تعدل الشيفرة أو الاختبارات لإصلاحه.

## أسئلة القرار لمالك النظام

1. هل النظام لمستأجر واحد أم عدة مدارس، وما قواعد العام الدراسي الحالي والصفوف المشتركة؟
2. ما العميل الإداري الرسمي الذي يستدعي الدوال، ومن يملك دورة تسليم بيانات دخول الطالب؟
3. ما سياسة الوصول المقبولة لصور ووثائق الطلاب وmetadata محاولات الدخول؟
4. هل يجب أن تمر المدفوعات وتعديلات النتائج حصريًا عبر RPCs ذرية؟
5. ما القواعد الرسمية للتقويم والنتائج واعتمادها واكتمال البيانات؟
6. ما أهداف الأداء والتوافر والنسخ الاحتياطي والاستعادة والاحتفاظ؟
